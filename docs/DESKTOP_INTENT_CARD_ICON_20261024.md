# 意图卡片与应用图标

当前消息下方显示紧凑的 JEV 卡片：沟通目的、选项概率、回复方向。新增 purpose Choice 与主题、资料充分性共用一次 JEV 请求，初判完成即显示，不增加候选回复区。

目的覆盖确认已了解、结束咨询、明确选款、比较、适配、商品身份误解、询价、配送、售后、定制、顾虑、推荐、详情、招呼与不明确。低把握显示“需确认”；选项概率不是正确率，界面注明这是模型判断，不把推测称为真实心理。

高把握的确认/感谢/招呼进入 SOCIAL_REPLY，仅简短回应，生成输入不携带商品事实，避免重复推销。“好的，多少钱？”仍按询价处理。切换买家或商品清空旧卡片，异步结果校验消息、会话版本、商品和取消状态。

应用图标是自绘蓝色聊天气泡与青绿勾号。SVG 和生成脚本在 DesktopClient/Assets；ICO 包含 16、20、24、32、40、48、64、128、256 像素帧。EXE ApplicationIcon、WPF 窗口和托盘使用同一资源。

验证：卡片/图标 9 项、JEV 流程 23 项、自动回复 21 项、桌面集成 37 项通过。虚构资料的真实接口测试确认“好的”归 ACKNOWLEDGE 并简短回复；“好的，多少钱？”归询价；“我要黑色款一个”归明确选择。没有上传真实买家资料。

接口参考 TypeSafe 官方 [Choice](https://docs.typesafe.ai/primitives/choice) 与 [Confidence](https://docs.typesafe.ai/confidence) 文档。
