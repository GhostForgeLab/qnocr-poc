# 桌面日志与诊断导出

- 独立日志页面：级别即时保存、打开目录、24 小时 / 7 天 / 全部已保留范围、后台 ZIP 导出。
- 结构化事件覆盖启动退出、可捕获异常、窗口连接/断开、识别状态、消息角色和数量、会话恢复、回复开始/结束/取消/复制/重试、商品保存和建议检查。
- 默认信息；调试事件不记录 OCR 文本或截图。窗口/会话/消息/预览/模型标识使用本机盐的 HMAC 引用，盐不导出。模型仅输出固定家族名与散列，不输出任意配置字符串。
- 错误只保存已知类型、HResult 和项目代码方法/文件名/行号，不保存 Exception.Message、完整堆栈路径、请求或响应正文。
- 日志按 UTC 日期与大小分段，约 2 MB 每段、最多 10 段、7 天保留；写入失败不导致主流程失败。
- ZIP 仅生成 manifest.json、events.jsonl、calls.jsonl、README.txt。导出重新解析并校验字段，不原样复制日志或审核记录；既有调用摘要显式排除 RejectedDraft、聊天和配置密钥。
- 最大 10000 条事件、1000 份调用摘要；超限/损坏记录计数。导出先写临时文件，完成后替换目标；取消不破坏原目标。
- 程序与核心 DLL 的 SHA256 帮助定位朋友实际运行的构建。CLI 导出在读取/解密 UI 配置前可用。

验证：14 项级别、轮换、并发、隐私 canary、时间范围、取消、跨窗口汇总和 UI 持久化检查；38 项桌面集成（含实际生成/复制事件）；21 项双向上下文回归。测试中只使用本机模拟接口，没有外部模型请求或消息发送。

测试者操作说明见 `TESTER_LOG_GUIDE.md`。
