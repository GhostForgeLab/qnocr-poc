QN Agent · 千牛客服助手 — 免安装测试版

一、打开软件
1. 使用 Windows 10/11 64 位电脑（Intel/AMD x64）。本包不面向 Mac、32 位 Windows 或 ARM 电脑。
2. 将 ZIP “全部解压”到自己有写入权限的文件夹，例如 D:\QNAgent。不要在压缩包内直接运行，不要放在 Program Files。
3. 双击 QNAgent.exe（图标为蓝色聊天气泡）。不需要安装 .NET、Python、开发工具或配置环境变量。
4. 请保留整个文件夹中的 DLL 和其他文件；只复制 EXE 无法运行。qnocr-poc.exe 是后台识别组件，不用打开。

二、首次设置（需要自己准备模型服务账号和密钥）
1. 在电脑上打开并登录千牛，打开接待中心，保持要读取的聊天窗口可见。
2. 助手 → AI 设置：填写回复模型的服务地址、模型名和 API Key，保存并测试。
   默认显示的模型名只是初始值，请改为自己的服务实际支持且有权限使用的模型。
3. 同页配置 JEV 服务地址、模型和独立 API Key。当前流程需要回复模型和 JEV 两套服务。
   密钥由测试者自行填写，本包不附赠模型额度。访问服务需要联网，调用费用由对应服务账号承担。
4. 助手 → 店铺与备份：填写显示名称并新建自己的店铺，点击“用于连接 / 新增商品”。
   固定店铺 ID 创建后不变；同名不代表同一家店。旧版本资料会自动登记固定 ID。
5. 助手 → 商品与知识库：新增真实商品，或导入负责人另行提供的商品 JSON。
   核对内容后勾选“我已核对这些商品资料，允许用于当前商品的 AI 回复”，保存。
   导入的商品也需要重新核对；初始商品库为空。
6. 助手 → 千牛连接：使用所选店铺的固定 ID，点击“刷新窗口”，选择接待窗口，再点“添加窗口连接”。
   多个店铺可逐一添加，分别使用对应的店铺标识。完成后点“收起设置，显示全部助手”。

三、日常使用
1. 在千牛打开买家的会话，等待助手识别；检查当前买家和商品是否正确，必要时手动选商品。
2. 首屏历史只载入；可手动生成回复。已核对商品确定后，新买家消息可自动生成一条建议。
   建议参考最近 10 条买卖双方对话；卖家回复时只更新上下文，保留界面和草稿。
3. 人工核对或修改建议，点击“确认并复制”，到千牛粘贴并发送。
4. 助手不会自动发送消息。只读取当前显示的窗口，不能读取隐藏会话或平台实时库存。
5. 生成回复会将相关对话文本、商品资料发送给所配置的 AI 服务。截图识别在本机完成。
6. 关闭设置窗后，有连接时程序可能仍留在托盘。完全退出请点击“退出助手”或托盘的退出。

四、本版新增的备份和学习
1. “店铺与备份”可导出 .qnbak 业务备份。换电脑先恢复备份、再选择原店铺，不要重新新建同名店铺。
   恢复先预览新增和冲突项，默认保留本机冲突资料，恢复前会自动备份；操作前先保存表单并断开助手连接。
2. 业务备份包含店铺、商品、优惠、资料建议、学习建议和已确认经验，不包含 API 密钥、AI 连接设置、原始聊天库或窗口绑定。
   新电脑需重新配置模型及密钥。请把备份另存到不会被重装清除的位置。
3. “学习建议”会尝试收集你没有采用 AI 建议、而自行回复的文字差异，再由 AI 设置中的模型分析。
   查看原建议、人工回复和原文依据，必要时修改，点击“核对无误，确认生效”。也可忽略或停用。
   未确认建议不会影响回复；第一版经验仅用于同店同商品，商品事实变化后需要复核。
4. 学习分析会将尽量去标识的问答片段和商品资料发送到已配置的模型服务；不需要时可关闭自动收集。
   不回扫全部聊天历史，不自动修改商品字段、不训练模型权重，不自动发送买家消息。
5. 业务备份属于私有资料（学习建议包含问答片段），与可供排错的“诊断 ZIP”不同，不要将业务备份当作日志发给他人。
6. 建议测试：切换不同买家；卖家回复后草稿保持不变；自行建立合成商品并备份、在另一份空白助手中恢复；忽略与确认学习建议。

五、反馈问题
1. 记下问题发生的时间、操作步骤、预期结果和实际结果。
2. 打开“日志与诊断”。需重现问题时切换“调试”，重现一次，再导出最近 24 小时的诊断包。
3. 将导出的 ZIP 和问题说明发给测试负责人。程序不会自动上传。
4. 诊断包排除 API Key、聊天正文、模型回复、截图、店铺/买家名称和商品数据库。
   不要发送整个 Data 文件夹。自己补充的截图请先遮挡买家资料和密钥。

六、数据、更新和删除
首次运行会在 QNAgent.exe 同级生成 Data 文件夹，保存本机设置、商品、聊天、学习及诊断数据。
本次收到的原始 ZIP 不包含任何密钥、商品资料、聊天记录、截图或学习记录。
密钥按 Windows 当前用户加密，搬到其他电脑或其他账户后需重新填写。
更新时先退出助手并备份 Data，再将新版本解压到新的文件夹，把旧 Data 复制到新版本同级目录。
上述复制 Data 仅用于自己同一电脑账户的版本升级；换电脑迁移业务请使用 .qnbak 恢复，并重新填写密钥。
确认新版本运行正常前保留旧文件夹和备份。不要同时启动两份助手连接同一接待窗口。
转发测试版请发送原始 ZIP，不要把已使用的文件夹重新压缩给别人。
无需卸载；退出后可删除程序文件夹。删除其中的 Data 会一并删除本地资料，请先备份需要的内容。

七、常见问题
• 找不到窗口：确认千牛接待中心已打开且未最小化，点击“刷新窗口”。
• 没有建议：检查两套 AI 配置、网络、商品核对状态、店铺标识和当前商品；尝试手动重新生成。
• 打字卡顿：在千牛连接关闭“快速识别”，或调大检查间隔，保存后重新连接。
• 系统提示未知发布者：这是未做代码签名的内部测试包。先核实文件来自测试负责人；受管电脑按公司要求处理，不要关闭防护软件。
• 无法启动：先确认 ZIP 已完整解压且目录可写，记录完整错误；运行依赖已打包，仍需在不同电脑上验证兼容性。
