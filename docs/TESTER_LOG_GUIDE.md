# 朋友测试：导出诊断日志

1. 在助手设置窗口左侧打开 **日志与诊断**。
2. 平时使用 **信息**；准备复现问题时切换到 **调试**，立即生效并保存。
3. 复现一次问题，记住大概时间和操作步骤。
4. 选择 **最近 24 小时**（跨天问题可选最近 7 天），点击 **导出诊断包（ZIP）**。
5. 将 ZIP 和问题时间、操作步骤交给测试负责人。程序不会自动上传或发送。

日志级别包含更严重事件：错误、警告、信息、调试。日志最多保留 10 个分段，每段约 2 MB，并清理超过 7 天的事件文件。过去未记录的调试信息不能补回。

压缩包只包含程序构建指纹、Windows/.NET 环境、不含密钥的配置状态、结构化错误及代码位置、调用状态/耗时/JEV 分类概率、上下文数量与散列关联标识。**不包含 API Key（包括加密值）、聊天正文、模型回复、截图、店铺或买家名称、完整网址、商品资料或数据库。**

诊断包中的调用摘要可能来自旧预览或人工修订关联，不应直接累加当作模型计费次数。超过数量限制或损坏的记录会在 manifest 中注明省略数量。

如果运行环境齐全，但设置窗口因配置等问题无法打开，可以从程序目录运行：

```powershell
.\QNAgent.exe --export-diagnostics "D:\QNAgent-diagnostics.zip"
```

该命令导出最近 7 天的技术信息，不需要解密模型密钥或启动千牛连接。路径可换成自己的可写位置。

发测试程序时，不要附带自己已有的 `Output/DesktopClient` 数据目录；其中保存着店铺资料、聊天及本机加密配置。朋友应使用自己的数据和模型配置。诊断 ZIP 也不需要人工打包整个数据目录。
