# 桌面 JEV 回复流程验证

本次接入桌面独立的异步 `JevGateway`，保留既有命令行 JEV 分类器及其他运行模式。旧桌面关键词分流已从生成路径移除。API 契约依据 TypeSafe 官方 [System One](https://docs.typesafe.ai/api/system-one)、[Choice](https://docs.typesafe.ai/primitives/choice) 及 [citation checking](https://docs.typesafe.ai/cookbooks/citation_check) 文档核对。

## 行为

1. 先校验当前窗口、买家、消息、商品店铺及商品核对状态。
2. 同一份商品资料和会话发送到 JEV，一次请求内独立判断意图和资料充分性。
3. 根据资料判定生成纯文本回复或直接提示人工核实。部分可回答时只允许有据事实，其余追问/核实。
4. 生成后使用同一份资料核验全部事实，任一事实不支持、核验不确定或服务失败时不展示原草稿。
5. 除“烟盒”商品名称外阻止其他带“烟”的表述；Markdown 清理不会破坏尺寸乘号。人工编辑后复制也执行格式/用词检查。

JEV 低置信度不会被当作可靠结论。曾在真实测试中观察到同一部分回答问题的概率波动；未达到阈值的判定保守回退。阈值不是模型正确率，仍保留人工确认和复制流程，不自动发送。

## 验证结果

- JEV 受控 HTTP 流程：15 项通过，包含先后顺序、完整/部分/追问/核实、错误兼容性结论拦截、不可用/无效分布/取消、限制用词重写及拒绝。
- 桌面集成：37 项通过，使用显式注入的测试 JEV，不调用真实模型。
- 多窗口隔离：20 项通过，包含异步旧回复不得覆盖新买家。
- 商品编辑：15 项通过。
- 真实 JEV 返回模型：`jev-1.14.0`（配置别名为 `jev-latest`）。材质可回答、仅外尺寸需核实、不同价格未选款需追问、虚构包装适配结论被拦截。
- 已配置回复模型 + 真实 JEV：三条虚构商品测试通过。材质回答为“这款烟盒的材质是纯钛。”；部分回答先提供测试价格，再明确包装适配尚不确定；不同款价格追问具体款式。均通过二次依据核验，未含 Markdown 星号或限制用词。

真实检查只使用虚构商品资料，没有读取真实买家消息或执行发送。测试价格不代表真实商品价格。
